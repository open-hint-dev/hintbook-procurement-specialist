## Shared common core

The unchanged common core is `never`, `source`, `term`, `assumption`, `risk`, `decision`, `openquestion`, `checklist`, `style`, `example`, `good`, `bad`, `read`, `res`, `notes`. See the [core documentation](https://github.com/open-hint-dev/hint/blob/main/docs/05-hintbooks.md#common-core-and-composition).
